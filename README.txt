MemeGuard na iPhone/iPad – jak uruchomić

Aplikacja to zwykła strona internetowa, więc trzeba ją raz wrzucić na darmowy hosting.

1. Na komputerze rozpakuj memeguard-ios.zip (wyjdzie folder memeguard-ios).
2. Wejdź na https://app.netlify.com/drop i przeciągnij folder memeguard-ios na stronę.
3. Dostaniesz link, np. https://cos-tam-123.netlify.app. Załóż darmowe konto
   (np. przez Google) i kliknij "Claim", żeby strona nie zniknęła.
4. Na iPhonie/iPadzie otwórz ten link w Safari → Udostępnij → "Do ekranu początkowego".

Aktualizacja: przeciągnij nowy folder w tym samym projekcie Netlify (Deploys → przeciągnij).
